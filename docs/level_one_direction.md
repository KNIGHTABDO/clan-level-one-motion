Clan Level One is not an artificial, corporate esports conglomerate, nor is it a fly-by-night TikTok meme circle. Its history represents one of the most remarkable grassroots movements in modern Arab digital culture:
- **2021 (The Genesis):** Six streamers playing *Grand Theft Auto V* Roleplay (FiveM / Mystery Town) gathered casually around late-night RP scenarios (*"جمعة العيال"*).

## 3. Strict Anti-Slop Rules (Non-Negotiable Constraints)

Every frame produced by `@motion` must pass this audit. Any violation is grounds for immediate rejection by `@verifier`.

### Rule 1: Screen Shake (Impulse Physics Only)
* **FORBIDDEN:** Continuous noise/wiggle during typography holds; constant handheld camera wobble on UI text; arbitrary sinusoidal shaking on weak snare hits.
* **PERMITTED:** Triggered **exclusively** on diegetic physical collisions (e.g., the logo stamp locking onto the canvas, the 2.70s Braam hit, or the 3.80s vocal transient).
* **MATHEMATICAL CEILING:**
  * Maximum duration: **8–12 frames (133–200 ms)**.
  * Maximum translation: **±12px** on frame 0, decaying exponentially via $A(t) = A_0 \cdot e^{-0.35 \cdot \text{frame}}$.
  * Maximum rotation: **±0.7°**. Never exceed 1.0°.

### Rule 2: Chromatic Aberration & Lens Fringing
* **FORBIDDEN:** Permanent RGB split across readable typography or fullscreen plates.
* **PERMITTED:** Sub-pixel optical dispersion strictly in the outer 20% radial vignette (max 1.5px R/B channel offset), OR a transient 3-frame strike spike (max 4.0px horizontal offset) on the exact frame of a brand stamp impact, immediately snapping to 0.

### Rule 3: Glitch & Signal Artifacts
* **FORBIDDEN:** Generic VHS tape noise, retro datamosh plugins, or arbitrary "matrix/cyberpunk" block glitches.
* **PERMITTED:** Micro-telemetry signal interruptions lasting **strictly 1 to 2 frames (16–33 ms)**: clean rectangular horizontal displacement bands (±16px offset, 2–3 bands max) accompanied by a 1-frame inverted monochrome flash.

### Rule 4: Glows & Optical Halations (The Two-Layer Law)
* **FORBIDDEN:** Single-pass CSS `box-shadow` or `drop-shadow(0 0 30px #EC5916)` at high opacity, which washes out blacks into a muddy pastel puddle.
* **MANDATORY DUAL-PASS LAW:** Every emissive element must render two distinct physical layers:
  1. **Tight Specular Core:** Radius 4–8px, high intensity (0.75–0.90 opacity), shifted towards white/amber (`#FF8A4C` for orange, `#88FFE9` for cyan).
  2. **Atmospheric Scatter:** Radius 36–72px, ultra-low intensity (0.12–0.22 opacity), pure brand hue (`#EC5916` or `#27DDC0`) with `mix-blend-mode: screen`.

### Rule 5: Transition Motivation & Vector Inheritance
* **FORBIDDEN:** Unmotivated whip-pans, circular Iris wipes, random spin-zooms.
* **MANDATORY:** Every cut must inherit the exit velocity vector of the previous element. If the lightning bolt slashes downward-right at 2800px/s, the next shot’s camera wipe must enter along that identical vector and decelerate smoothly.

### Rule 6: Typography Animation Restraint
* **FORBIDDEN:** Bouncing cartoon rubber overshoot ("clown physics"); character-by-character typewriter effects on hero titles; text flying in from screen edges with heavy directional motion blur.
* **MANDATORY:** Architectural masking (`clip-path: inset(...)` or `overflow: hidden`) paired with tight vertical reveals and exponential deceleration. Text emerges from the obsidian void like monolithic architecture.

### 4.2 HarfBuzz Compliance & Arabic Layout Laws
1. **ZERO Tracking on Arabic Text (The Immutable Rule):** Modifying CSS `letter-spacing` on connected Arabic script breaks contextual glyph shaping (initial, medial, final ligatures). Tracking is strictly locked to `0`.
2. **No Character Splitting:** Never split Arabic strings into single character spans (`text.split('')`). Animate at the word level, or use `clip-path` masks, or render outlined SVG paths.
3. **Right-to-Left (RTL) Mask Direction:** When wiping or masking Arabic phrases, the clip path must advance from Right to Left (`clip-path: inset(0 0 0 100%)` → `inset(0 0 0 0%)`), respecting Arabic cognitive reading flow.
4. **Optical Mass Calibration:** Because Arabic letterforms lack Latin cap-height uniformity, scale Arabic display text to **1.14x–1.18x** of the paired Latin headline so both hold identical visual authority.

### 5.2 Lighting & Shader Principles
- **Volumetric Rim Opposition:** Treat typography and cards like physical luxury objects. Apply a top-left Fiery Orange rim highlight (`#EC5916` at 75% opacity) and a bottom-right Electric Cyan counter-key (`#27DDC0` at 25% opacity).
- **Anamorphic Streak:** On major downbeats, trigger a 2px-tall horizontal streak spanning the width of the frame, tapering from transparent to `#EC5916` to pure `#FCFEFE` at center.
- **Atmospheric 24fps Grain:** Overlay procedural fractal noise at `opacity: 0.045` with `mix-blend-mode: overlay`. Crucially, update the grain seed at 24fps (`Math.floor(frame / 2.5)`) inside the 60fps canvas. This prevents H.264 compression banding and injects organic 35mm film character into 60fps kinetic motion.

### 6.3 Eye-Trace Control & The 90/10 Principle
1. **The 90/10 Rule:** Maintain controlled stillness or micro-drift (scale `1.000 → 1.025`) for 90% of a scene's duration. Detonate ballistic state changes in the remaining 10% (4–9 frames). Stillness makes the impact hit.
2. **Central Focal Lock:** Anchor the viewer’s eye inside a 240×240px circle at screen center `(0.5W, 0.5H)`. The horizon seam ignites at center, splits outward from center, the logo slams into center, the Play button pulses at center, and the lightning tail directs focus downward to the hashtag.

### 8.2 Master Motion Interpolator (`kit/src/utils/levelOneMotion.ts`)

```typescript
import { spring } from 'remotion';

export const clamp = (v: number, min = 0, max = 1) => Math.min(max, Math.max(min, v));

export const exponentialDecay = (frame: number, decayRate = 0.35) => {
  return Math.exp(-decayRate * Math.max(0, frame));
};

export const getImpulseShake = (frame: number, impactFrame: number, maxAmplitude = 11) => {
  const elapsed = frame - impactFrame;
  if (elapsed < 0 || elapsed > 12) return { x: 0, y: 0, rot: 0 };
  const decay = exponentialDecay(elapsed, 0.38);
  // Deterministic pseudo-random oscillating impulse
  const sign = elapsed % 2 === 0 ? 1 : -1;
  return {
    x: sign * maxAmplitude * 0.4 * decay,
    y: -sign * maxAmplitude * decay,
    rot: sign * 0.65 * decay,
  };
};
```
